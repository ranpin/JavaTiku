# JavaTiku（Java2 实用教程第 5 版配套练习题库）

《Java2 实用教程（第 5 版）》（耿祥义 编著）的官方配套练习题库软件，version T1。一个用 Java Swing 编写的桌面程序，按教材章节顺序组织题目，供学生练习并即时查看答案、统计正确率。

> 说明：仓库里只有编译好的 `Tiku.jar`（无 Java 源码），并自带一套 Windows 版 JRE，双击 `runApp.bat` 即可运行。

## 题库规模

共 **1243** 道题，按教材章节顺序组织（第 1 章 ~ 第 15 章），四种题型：

| 题型 | 数量 | 作答方式 |
| --- | --- | --- |
| 判断题 | 537 | 二选一（正确 / 错误） |
| 选择题 | 361 | 四选（可多选） |
| 挑错题 | 151 | 在标注 A/B/C/D 的代码中选一处错误（单选） |
| 读程题 | 194 | 阅读代码后在文本框中填写输出结果 |

练习时可随机抽题，也可按题库顺序逐题做；随时查看当前题答案和累计正确率。

## 如何运行

**Windows 下直接运行**（仓库自带的 JRE 为 Windows 32 位版本）：

```
双击 runApp.bat
```

`runApp.bat` 的内容就是把 `PATH` 指向自带的 `.\jre\bin`，然后 `start javaw -jar Tiku.jar`。启动时按说明文档要求输入使用密码（密码见仓库根目录的《…练习题库说明.doc》，此处不公开）。

**其他平台 / 自带 JRE**：仓库里的 JRE 只适配 Windows。若在别的系统或想用本机 Java 运行，可直接：

```bash
java -jar Tiku.jar
```

（程序入口为 `quesion.view.AppRun`，见 jar 内 `MANIFEST.MF`。）

```
├── jre/                     # 自带的 Windows 32 位 JRE
├── Java2实用教程第5版配套练习题库说明.doc   # 官方使用说明（含密码、题型介绍）
├── 密码.txt                 # 使用密码（与说明文档一致）

├── 题库/                    # 题目数据，按章节组织
│   └── 第N章/
│       ├── 判断题.data
│       ├── 选择题.data
│       ├── 挑错题.data
│       └── 读程题.data
├── 判断题图/  选择题图/  挑错题图/  读程题图/   # 各题型配图
```

### 数据组织方式

- `题库/` 下共 15 个章节目录，每章 4 个 `.data` 文件（共 60 个），分别对应四种题型。
- `.data` 是 **Java 序列化文件**（`java.util.ArrayList`，元素为 `quesion.data.Problem`，字段含题干 `content`、正确答案 `correctAnswer`、选项 `giveChoiceA~D`），由程序直接反序列化读取，不是给人读的文本。
- 四个「题图」目录存放题目配图，命名为 `图<章>_<序号>.jpg`；无配图的题目统一用各目录下的 `无图.jpg` 占位。

## 注意事项

- 官方说明文档明确要求：**不要删除或修改除说明文档以外的任何文件或文件夹**，题库数据与配图缺失都会导致程序无法正常读题。
- 本仓库仅归档发行版（jar + 数据 + JRE），不含源码，无法直接二次开发。
